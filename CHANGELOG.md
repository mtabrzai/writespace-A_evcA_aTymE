## [Unreleased]

## [0.1.0] - 2024-02-20
### Added
- Initial project setup with Vite + React + TypeScript
- Core routing system with React Router DOM
- Authentication flow with login and registration pages
- State management using Zustand
- Document management system with CRUD operations
- Blog post management within documents
- Rich text editing with Markdown support (react-markdown + remark-gfm)
- Responsive UI components with Tailwind CSS
- Admin dashboard for user, document, and post management
- Favorites and tagging system for documents and posts
- Search and filtering functionality
- Dark mode support via Tailwind CSS
- Testing infrastructure with Vitest and Testing Library
- Environment configuration and constants

### Changed
- Improved error handling across all components and stores
- Enhanced loading states with skeleton loaders
- Optimized performance with lazy loading and memoization

### Fixed
- Various UI inconsistencies and responsive design issues
- State synchronization between local storage and Zustand stores
- Type safety improvements across the codebase
